🎬 WASM Video Player - Demo & Setup Guide

🚀 Quick Start

Follow these steps to get the video player running:

Step 1: Install Prerequisites

Make sure you have Rust and Node.js installed:

# Install Rust (if not already installed) curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh # Install wasm-pack cargo install wasm-pack # Install Node.js dependencies npm install

Step 2: Build the Project

Build the WebAssembly module:

# On Windows build.bat # On Linux/Mac ./build.sh # Or manually npm run build

Step 3: Start the Server

Start the development server:

npm run serve

Then open http://localhost:8000 in your browser.

🎯 Features Demonstration

Supported Video Formats

  • MKV - Matroska Video (common for high-quality videos)
  • AVI - Audio Video Interleave (legacy format)
  • MOV - QuickTime Movie (Apple format)
  • WMV - Windows Media Video
  • FLV - Flash Video
  • WebM - Web Media (Google format)
  • MP4 - Already supported natively

Processing Pipeline

  1. File Upload - Drag & drop or file picker
  2. Format Detection - Rust checks file extension
  3. Worker Processing - FFmpeg.wasm converts in background
  4. Progress Reporting - Real-time conversion progress
  5. Subtitle Extraction - Automatic subtitle detection
  6. Playback - HTML5 video with subtitle tracks

🔧 Technical Architecture

Rust WebAssembly (src/lib.rs)

  • File handling and validation
  • Progress callback management
  • Worker message coordination
  • Browser API integration

FFmpeg Worker (ffmpeg-worker.js)

  • Video format conversion
  • Subtitle extraction
  • Progress reporting
  • Background processing

Frontend Integration (index.html)

  • Drag & drop interface
  • Progress visualization
  • Video playback controls
  • Subtitle management

🧪 Testing the Player

To test the video player:

  1. Find a video file in MKV, AVI, or MOV format
  2. Open the main application at http://localhost:8000
  3. Drag the video file onto the upload area
  4. Watch the conversion progress
  5. Play the converted video
  6. Test subtitle functionality if available

Note: The first load may take a moment as FFmpeg.wasm downloads from the CDN.

🐛 Troubleshooting

Common Issues

  • Build fails: Ensure Rust and wasm-pack are properly installed
  • FFmpeg not loading: Check internet connection for CDN access
  • Conversion fails: Try with a smaller or different video file
  • CORS errors: Make sure to serve files via HTTP server, not file://

Browser Requirements

  • WebAssembly support
  • Web Workers
  • HTML5 Video
  • File API
