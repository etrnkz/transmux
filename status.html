🔧Quick Fixes

  • FFmpeg not loading: Run npm run setup-ffmpeg to download files locally
  • Worker errors: Check that you're using HTTP server (not file://)
  • CORS issues: Use npm run serve to start proper server
  • Format not supported: Try MP4, WebM, or OGG for direct playback
